# PR16 reconstruction candidate, 2026-09-13

No new physical C5 measurement in this directory. At preparation time the C5
was absent from USB; the user must connect it before the RF-off oracle.

`synthetic-spectrum.json` and `.png` are generated by
`python tools/report_linear80_spectrum.py`. They show mathematical
reconstruction of a quantized synthetic tone, not VTX noise or actual GPIOs.

Both merged images start at flash offset 0. Preserve the existing firmware
before flashing. Flash **the oracle first**, with VTX off. Its record starts
at `diagcap` offset `0x112000`; extract 65856 bytes or the entire partition.
Analyze using `python tools/analyze_linear80_oracle.py capture.bin`.

Require zero unexplained byte mismatches, valid setup/completion, no midstream
FIFO read-empty flag, and correct incremental duration at 40/80 MHz. Two input
lengths remove fixed setup cost approximately; this is not an independent
oscilloscope measurement. All startup/trailing discrepancies remain visible.

Only after the physical gate, test live with the VTX for a short, explicitly
coordinated interval. Compare baseline and candidate with the same scene,
distance, load and wiring. The 12.5 ns output clock does not prove analog
settling or guarantee aligned layers in weak RF. CPU240 profiles exist for
a separate clock A/B, with no per-sample CPU processing.
