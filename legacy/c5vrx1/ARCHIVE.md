# Original C5VRX archive

This directory is an unmodified tree snapshot of
[`Twotoz/C5VRX-archive`](https://github.com/Twotoz/C5VRX-archive) at commit
`ab79fd0410ef5dc6adb58083a6e72eecb6ed70b8`.

That repository was the original `Twotoz/C5VRX` before the modern project took
the canonical name. Its complete Git history is joined into the canonical Git
graph without rewriting original commits. Unique historical branches are
preserved under the `legacy/c5vrx1/` branch namespace.

The files here are historical evidence and are **not** the current firmware.

- Current implementation: `/main`
- Current hardware-proven findings: `/docs`
- Historical snapshot: `/legacy/c5vrx1`

Do not build legacy CMake files as part of the root project or copy old source
into current `/main` without checking why that path was replaced.

The archived material retains the license and notices under which it was
originally distributed. Its original `LICENSE` and `BRANDING.md` are preserved
in this directory.
